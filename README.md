# Technical Foundations & Web Architecture

Welcome to my consolidated web development workspace. This repository organizes my earlier hands-on projects built while exploring software development, structured using **Git Submodules** to preserve original development commit histories and timelines.

---

## Strategic Alignment & Career Transition
Before specializing in **Network Operations and Cybersecurity**, I built hands-on experience in full-stack web technologies (HTML5, CSS3, JavaScript ES6+, and Node.js). 

Understanding software architecture from the developer's perspective provides essential context for security operations:
- **Client-Server Dynamics:** Understanding how applications handle HTTP request/response cycles, headers, and payload structures informs network protocol analysis and traffic inspection.
- **Application Logic & APIs:** Hands-on work with REST APIs and asynchronous JavaScript helps evaluate how data flows through endpoints and where input validation risks occur.
- **Environment & Version Control:** Practicing Git workflows, CLI operations, and structured documentation laid the foundation for managing enterprise infrastructure and lab configurations[cite: 1, 2].
